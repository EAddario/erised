## Agent skills

### Issue tracker

Issues live as markdown files under `.ai/scratch/`. See `.ai/docs/agents/issue-tracker.md`.

### Triage labels

Default triage labels used as-is (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `.ai/docs/agents/triage-labels.md`.

### Domain docs

Single-context repo — one `CONTEXT.md` at root, ADRs in `.ai/docs/adr/`. See `.ai/docs/agents/domain.md`.
